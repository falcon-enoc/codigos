# 🎵 Conversor de .MOV a .MP3 con Python y MoviePy

Este script permite **extraer el audio de un archivo de video `.mov`** y guardarlo en formato `.mp3`.  
Funciona usando la librería [MoviePy](https://zulko.github.io/moviepy/), que a su vez utiliza `ffmpeg` de fondo (lo descarga automáticamente si no está instalado).

---

## 🚀 Requisitos

- Python **3.7 o superior**
- [pip](https://pip.pypa.io/en/stable/)
- Librería **MoviePy**

Instalación:

```bash
pip install moviepy
